# Architecture rules
- Plan/entitlement source of truth is the `purchases` table written only by the verified payment webhook (`src/routes/api/public/payments/webhook.ts`); local `tier` in store.ts is a cache refreshed by `syncEntitlement` — never unlock from client events.
- Every purchase row carries `environment` (sandbox/live); all reads filter by it.
- AI trimmer quotas are enforced server-side in `ai_usage` inside `suggestSegments`; only small JPEG stills are sent, never the video file.
- Webhook converts scheduled subscription cancels into immediate cancels to match the "cancel = access ends now" rule.

- Legal routes render both language versions as separate language-tagged sections rather than relying on device language, so both are publicly readable.
- Reuse LegalLinks on the app home screen and both onboarding steps so legal pages remain accessible without an account.
- Premium library sync stores only folder/clip metadata in `library_sync`, written via server fn after a server-side premium check; videos never sync.
- Admin payments dashboard reads only from payment_events (logged by the verified webhook) and is gated by user_roles admin role server-side.
- Service worker is generated by vite-plugin-pwa into dist/client and registered only via src/lib/pwa.ts (never in dev/preview/iframes); navigations are NetworkFirst so SSR pages never go stale. Manifest is hand-written in public/manifest.webmanifest.
- Session playback transitions and timers live in useSessionPlayback; mount only after the routine is available and count video work time only while media is playing; explicit timer-only or missing-source steps count independently to avoid hydration and loading races.
- Clip title drafts may be blank in the editor, but updateClip preserves a nonempty persisted name so exiting without blur cannot save an empty title.
- Normalize segment ranges through clampSegmentRange at editor and persistence boundaries using fractional media metadata, so slider and AI results cannot exceed the source.
- SegmentBuilder owns its nested upgrade dialog so free AI taps open an actionable sheet without discarding the current clip draft.
- ClipDeleteDialog gates irreversible clip and video cleanup behind explicit confirmation so cancellation has no side effects.

- Folder parentId is normalized on local load and every state update, including sync; missing parents and cycles become roots so legacy libraries stay navigable.
- Removing clip videos deletes local blobs and revokes cached URLs, then detaches every shared reference without changing step names or durations so other clips cannot hold broken sources.
- The active library stores folders and single-source clips with segments only; migrateLibrary converts old local or synced containers once at read boundaries, drops empty containers, preserves source keys, ranges, durations and access flags, and never writes legacy containers.
- Clip creation uses only the header menu and saves directly to the current folder after segment confirmation; /clip/$id edits one source, /play/$id plays it, and folder sessions are transient selections preserving internal segment rests without a persisted group entity.
- Capacitor iOS loads the hosted HTTPS app with the iPhone-mode flag because TanStack server functions require the Worker; native packaging stages only client assets into dist and never bundles server output.
- Track the generated iOS Xcode/SPM source project; Codemagic supplies Apple signing externally so certificates and generated build products never enter the repository.
